# بات پونز برای بله

نسخه آزمایشی بات خصوصی حضور و غیاب و ثبت موارد انضباطی.

## امکانات فعلی
- ثبت عضو با شناسه عددی بله
- نقش‌های مدیر اصلی، مسئول ثبت و عضو
- ثبت حاضر، غایب، تأخیر و موجه
- ثبت موارد انضباطی
- مشاهده سوابق شخصی
- گزارش روزانه

## استقرار روی Render
1. مخزن را به Render متصل کنید.
2. متغیرهای محرمانه را در بخش Environment وارد کنید:
   - `BALE_BOT_TOKEN`: توکن بات بله
   - `DATABASE_URL`: رشته اتصال PostgreSQL پروژه Supabase (از Connect در داشبورد پروژه؛ روش Session pooler یا Direct مطابق دسترسی هاست)
3. متغیرهای `BOOTSTRAP_ADMIN_USERNAMES` و `TIMEZONE` از قبل در render.yaml تعریف شده‌اند.
4. پس از Deploy، آدرس سرویس را باز کنید؛ پاسخ سالم باید `database: connected` نشان دهد.
5. در بله به بات پیام `/start` بدهید.

## امنیت
- هیچ توکن یا رمز پایگاه داده‌ای در مخزن ذخیره نکنید.
- RLS روی جداول فعال است و دسترسی anon/authenticated بسته شده؛ بات فقط از سرور به PostgreSQL وصل می‌شود.
- نام کاربری مدیران اولیه فقط برای شناسایی اولین پیام استفاده می‌شود. پس از اولین ورود، شناسه عددی بله در جدول users ثبت می‌شود.
- پیش از استفاده واقعی مدرسه، API بله، مجوز مدیران و سناریوهای ثبت باید با حساب آزمایشی بررسی شوند.

## محدودیت نسخه
این نسخه از polling استفاده می‌کند. سرویس رایگان Render ممکن است هنگام بی‌کاری متوقف شود؛ بنابراین برای اجرای پایدار و دریافت همیشگی پیام‌ها باید webhook یا هاست همیشه‌فعال تنظیم شود.
